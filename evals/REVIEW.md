# Golden-set label review

Generated by `npm run labels:review` from `evals/leases/*.labels.json` and `evals/hard/*.labels.json` (hard set: edit `evals/hard/source/specs.ts`, then `npm run hard:build`). Don't edit by hand.
To approve a case, set `"approved": true` in its labels file. To change a label, edit the JSON and regenerate.
Label rules: docs/LABEL_POLICY.md. Severity: violation (forbidden conduct), void (unenforceable term),
notice (missing disclosure), review (a person should check). Optional = arguable; not scored either way.

30 cases (8 in the hard set): 17 dev (used for tuning), 13 test (held out; published numbers). Approved: 0.
